## Deskripsi Aplikasi
**Bloomlet** adalah website *Personal Task Organizer* berbasis web yang dirancang untuk membantu pengguna mengelola daftar tugas, prioritas, dan *deadline* kegiatan harian.

## Fitur Utama & Alur Sistem
1. **Simulasi Login**
   * Form login menerima parameter `username` dan meneruskannya ke seluruh halaman melalui URL Query Parameter.
2. **Dashboard Ringkasan**
   * Menampilkan statistik tugas harian (Total Task, Completed, In Progress, Pending) serta menyapa pengguna berdasarkan `username` login.
3. **Pengelolaan Task**
   * Menampilkan daftar tugas lengkap dalam bentuk tabel.
4. **Profil Pengguna**
   * Menampilkan identitas detail mahasiswa dan role sistem.
